# 格斗之王 v2.0 - Fighting King Online

基于 HTML5 Canvas 的双人格斗游戏，支持 **本地双人**、**人机对战** 和 **在线联机** 三种模式。

## 🎮 游戏模式

| 模式 | 说明 |
|------|------|
| 👥 本地双人 | 两人共用键盘对战 |
| 🤖 人机对战 | 挑战AI电脑对手（3个难度等级） |
| 🌐 在线对战 | 联网与远方朋友跨城市对战 |

## 🕹️ 操作说明

### P1 操作
| 按键 | 功能 |
|------|------|
| A / D | 左移 / 右移 |
| W | 跳跃 |
| S | 蹲下 |
| J | 拳击 |
| K | 踢击 |
| L | 必杀技（气满50%） |
| U | 防御 |

| 按键 | 功能 |
|------|------|
| ← / → | 左移 / 右移 |
| ↑ | 跳跃 |
| ↓ | 蹲下 |
| 1 | 拳击 |
| 2 | 踢击 |
| 3 | 必杀技（气满50%） |
| 0 | 防御 |

### 通用按键
| 按键 | 功能 |
|------|------|
| Enter | 确认 / 开始 |
| Esc | 返回菜单 |
| Q / E | 调整AI难度（人机模式） |
| M | 静音切换 |

## 🔊 音效系统

游戏内置完整的音效系统，使用 Web Audio API 程序化生成，无需外部音频文件：

- **打击音效**：拳击、踢击、必杀技、防御格挡
- **动作音效**：跳跃、飞行道具、KO
- **界面音效**：菜单选择、确认、回合开始、FIGHT!、胜利
- **背景音乐**：菜单BGM（轻松氛围）、战斗BGM（紧张激烈）

按 **M** 键可随时静音/取消静音。

## 🚀 快速开始

### 本地游戏（无需服务器）

直接用浏览器打开 `index.html` 即可游玩本地双人和人机对战模式。

```bash
# macOS
open index.html

# Windows
start index.html

# Linux
xdg-open index.html
```

### 在线对战（需要服务器）

在线对战需要运行 WebSocket 服务器。

#### 步骤 1：安装依赖

```bash
cd fighting-game
npm install
```

#### 步骤 2：启动服务器

```bash
npm start
```

服务器启动后，在浏览器中打开 `http://localhost:3000`。

#### 步骤 3：创建/加入房间

1. 选择「在线对战」模式
2. 按 Enter 连接服务器
3. 按 `1` 创建房间，或按 `2` 输入房间号加入
4. 将 6 位房间号发给朋友
5. 朋友输入房间号即可加入

## 🤖 AI 难度

| 难度 | 特点 |
|------|------|
| 简单 | 反应慢，攻击频率低，适合新手 |

## 🔧 技术细节

- **渲染**: HTML5 Canvas 2D
- **网络**: WebSocket 实时通信
- **同步**: 输入预测 + 延迟补偿
- **AI**: 基于状态机的决策系统

### 网络同步原理

1. 采用 **输入同步** 模式：每位客户端独立模拟游戏逻辑
2. 每 2 帧向服务器发送本地玩家的键盘输入
3. 服务器将输入转发给对手客户端
4. 客户端使用 2 帧延迟补偿来平滑对手动作
5. 双方都使用相同的本地键位 (a/d/w/s/j/k/l/u)，playerIndex 决定哪个角色是本地/远程控制

**注意：** 当前版本仅实现输入同步，未实现状态校正。如果网络延迟波动较大，双方画面可能出现轻微不同步。
